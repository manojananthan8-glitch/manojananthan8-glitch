**⚙️ Setup instructions**

The contribution snake requires a GitHub Actions workflow. Add the following file to your profile repository:

**File:** `.github/workflows/snake.yml`

```yaml
name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - name: Generate Snake
        uses: Platane/snk@v3
        with:
          github_user_name: manojananthan8-glitch
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Publish to Output Branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**To activate:**

1. Create the `.github/workflows` folder in your profile repository.
2. Create `snake.yml` inside it and paste the workflow above.
3. Commit and push the file to your `main` branch.
4. Open the **Actions** tab in your GitHub repository.
5. Run **Generate Contribution Snake** using **Run workflow**.
6. Check that the `output` branch is created and the SVG files are published.

The animation will appear once the workflow succeeds and the generated files are available.
