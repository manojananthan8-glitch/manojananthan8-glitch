Problem statement
Mechanical energy from everyday footsteps is generally not captured for
electrical use. This project explores whether that energy can be
harvested for suitable low-power applications.
Proposed solution
Develop a footstep energy harvesting setup that converts applied
mechanical pressure into electrical energy and explores IoT-based
monitoring.
System concept
Mechanical input: Pressure applied by footsteps.
Energy conversion: A suitable transducer converts mechanical
input into electrical output.
Power conditioning: Appropriate circuitry conditions the
generated output.
Storage: A suitable storage element may retain harvested energy.
Monitoring: An IoT-enabled controller may be used to monitor
system data, subject to the project's actual implementation.
Core areas
Footstep-based energy harvesting
Electrical conversion and conditioning
Potential energy storage
IoT monitoring concept
Testing and evaluation of generated output
Engineering challenges
The project involves considering variable footstep pressure, output
consistency, component selection, energy conversion efficiency, storage,
and practical installation constraints.
Engineering decisions
Component choices and design improvements should be based on measured
output, efficiency, durability, cost, and the intended use case.

Potential applications
Demonstration installations in educational institutions

Smart-infrastructure learning projects
Future scope

modular designs, monitoring performance, and assessing durability and
practical feasibility.

Enable the animation: Create `.github/workflows/snake.yml` in this
repository and add the workflow below. Then run it from the GitHub
Actions tab. The image will display after the workflow publishes the
`output` branch.
``` yaml
name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 0 \* \* \*"
  workflow\_dispatch:
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      - name: Generate snake
        uses: Platane/snk@v3
        with:
          github\_user\_name: ${{ github.repository\_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Publish snake
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target\_branch: output
          build\_dir: dist
        env:
          GITHUB\_TOKEN: ${{ secrets.GITHUB\_TOKEN }}
```
